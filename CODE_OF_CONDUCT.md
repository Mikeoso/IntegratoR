# Code of Conduct

This project follows the [Contributor Covenant Code of Conduct v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

By participating in this project, you agree to abide by its terms.

## Reporting

If you experience or witness unacceptable behaviour, please report it by contacting the project maintainer. All reports will be handled with discretion.

## Enforcement

Project maintainers are responsible for clarifying and enforcing standards of acceptable behaviour and will take appropriate corrective action in response to any instances of unacceptable behaviour.
