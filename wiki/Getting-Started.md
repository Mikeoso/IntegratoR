# Getting Started

Set up IntegratoR from scratch and send your first command to D365 Finance & Operations.

## Setup

- **[[Install-the-Framework]]** — Add IntegratoR NuGet packages to your project.
- **[[Configure-the-OData-Connection]]** — Point the OData client at your D365 F&O environment.
- **[[Register-Services-in-Your-Host]]** — Wire up dependency injection in your Azure Functions host.

## First Steps

- **[[Create-Your-First-Entity]]** — Define a C# class that maps to a D365 F&O data entity.
- **[[Send-Your-First-Command]]** — Create, update, and delete entities through the CQRS pipeline.
- **[[Run-Your-First-Query]]** — Retrieve entities by key or filter expression.
